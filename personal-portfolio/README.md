# NEXA Personal Portfolio (Website A)

Personal portfolio for **Aymen Jr.**, an AI Engineer. Showcases three engineering projects: Nexa Support, Nexa Order Intelligence, and Nexa Sales.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Notes

- No ACS commercial presentation (personal portfolio only).
- No contact form; closing links to GitHub profile.
